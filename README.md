# CC98 AI 主题总结（Chrome MV3 扩展）

在 cc98 论坛页面上直接**检索 → 抓正文 → 用 DeepSeek 作答 / 总结**，限速防封已内置。
支持"勾选帖子按主题总结"和"一句话问题自动搜索并回答"两条路径，结果都可**继续追问**。

## 功能

- **悬浮面板**：任意 cc98 页面右下角点看板娘打开；打开时自动**扫描本页**，
  把当前页（论坛搜索结果页 / 版面页）里的帖子列出来勾选。
- **问题式搜索**：面板输入一句话问题 → DeepSeek 拆成多组关键词（弥补 cc98 无模糊搜索）
  → 走官方接口检索 → 抓取前若干篇正文 → AI 直接给出**答案 + 参考帖列表**（可点击跳原帖）。
- **快速选中**：列表顶部「前 N 篇」（N 可改）+「全选」，一次勾选多篇。
- **主题总结**：输入总结主题 → 点「开始总结」，限速抓取楼层正文（UBB 已清洗为纯文本），
  DeepSeek **流式**输出到独立的大悬浮窗（可拖动、可复制）。
- **持续追问**：结果下方输入框可就刚才结果追问，会保留上文与本批原帖材料。
- **参考帖固定置底**：正文里引用的帖子在末尾汇总成可点击链接列表。

## 使用流程

1. 打开 cc98 的**搜索页或版面页**（登录令牌会自动捕获），点右下角看板娘。
2. 二选一：
   - 在顶部输入**问题** → 「搜索并回答」
   - 勾选帖子 → 输入**总结主题** → 「开始总结」
3. 结果在大悬浮窗里**流式**显示；需要深挖就在底部**继续追问**。

## 安装

1. 打开 Chrome，访问 `chrome://extensions`。
2. 右上角打开「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本文件夹。
4. 点扩展图标 → 「打开选项配置」，填入 **DeepSeek API Key**
   （在 [DeepSeek 开放平台](https://platform.deepseek.com/) 申请）。
   模型名默认 `deepseek-chat`，也可填官方新模型名 `deepseek-flash`。

## 登录令牌说明

插件**自动捕获**你在 cc98.org 浏览时的登录令牌：后台只读观察页面发往 `api.cc98.org`
的请求头里的 `Authorization: Bearer …`（不拦截、不修改、不重新登录、不存账号密码）。
打开任意 cc98 页面正常浏览几秒，面板顶行就会显示「已就绪：用户名」。

- cc98 令牌**有效期 1 小时**；过期后再浏览一下 cc98 页面即会自动重新捕获。
- 手动兜底：选项页可粘贴 F12 → Network → `api.cc98.org` 请求里的
  `authorization: Bearer …` 整串。
- 验证令牌时先试 `/me`，失败则回退到内容接口（`/me` 对手动粘贴的令牌可能不适用）。

## 防封号 / 速度限制

限速参数**在代码里硬编码**（`background.js` 顶部的 `RATE`），选项页只做展示，不可改：

| 参数 | 值 | 含义 |
| --- | --- | --- |
| `concurrency` | 3 | 同时抓取的帖子数（帖内仍串行翻页） |
| `baseDelayMs` + `jitterMs` | 1500 + 0~1500 | 帖内翻页间隔（带随机抖动） |
| `globalSpacingMs` | 150 | 全局请求最小间隔 |
| `searchMinIntervalMs` | 5000 | 搜索接口最小间隔（官方限流 5s/次） |
| `sizePerPage` | 20 | 每页楼层数 |
| `maxPages` | 5 | 每帖最多翻页数 |
| `maxTotalChars` | 60000 | 单帖正文总字符上限 |
| `maxRetries` | 3 | 429/403/5xx 指数退避重试次数 |

- 抓取时**复用浏览器真实会话**与真实 UA，与正常浏览无法区分。
- 触发限流自动**指数退避**重试，连续失败会暂停并提示。

## 技术要点

- 使用 cc98 官方 REST API（`api.cc98.org`，OpenID Bearer 认证）：
  - 搜索：`GET /topic/search?keyword=&from=&size=`
  - 楼层：`GET /Topic/{id}/post?from=&size=`（返回 UBB 正文）
  - 其他：`/topic/new`、`/me`、`/config/index`
- **关键词策略（实测驱动）**：cc98 搜索是**「与」语义**——关键词里每多一个空格就多一个
  必须同时出现的条件，命中数骤降。实测（问题「英语四六级对保研的影响」）：

  | 关键词 | 命中 |
  | --- | --- |
  | `保研` | 20（**大多跑题**） |
  | `保研 英语` | 20（**全部切题**） |
  | `保研 英语 要求` | 11 |
  | `保研 英语 要求 六级` | 5（**是上一条的子集**） |

  因此策略是：**输出多个 2 词组合、换限定词与同义词铺开覆盖面**，而不是堆词或降级到宽泛单词；
  对比型问题（"A 还是 B"）禁止输出裸单词，也禁止把 A B 合进同一个关键词。
- **选材按关键词轮询**：否则高召回的关键词会把名额占满，对比型问题里一方会把另一方挤掉。
- **Shadow DOM 隔离**：面板构建在 shadow root 内，避免被宿主页面样式、
  以及 Dark Reader 这类会改写页面颜色的扩展污染。
- UBB 清洗逻辑参考 [cc98-mcp](https://github.com/EviterLesRoses2/cc98-mcp)（MIT）。
- Markdown 渲染为自写的轻量实现（先转义 HTML，不引第三方库）。

## 已知限制

- 搜索接口限流 **5 秒/次**，多个关键词会串行等待，问题式搜索通常需要 20~30 秒。
- 0 命中时不会调用 AI，直接提示换个说法。
- 令牌 1 小时过期，任务中途过期需刷新一次 cc98 页面再重试。
