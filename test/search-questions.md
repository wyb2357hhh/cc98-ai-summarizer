# CC98 问题式搜索 —— AI 能力测试题库

用途：把这些**问题**逐一输入插件面板顶部的「问题搜索」，检验 AI 在「拆关键词 → 检索 → 读材料 → 作答」这条链路上的能力。

## 评分维度（每题按 5 项各打 1~5 分）

| 维度 | 看什么 |
|---|---|
| **拆词** | 第 1 步显示的关键词是不是**短词**（2~6 字）、有没有把长句拆开、有没有保留虚词 |
| **召回** | 第 2 步命中的帖子里，有没有真正相关的；命中数是否合理（不是 0，也不是一堆无关） |
| **接地** | 答案有没有引用具体楼层/标题，内容能不能在材料里找到对应 |
| **抗幻觉** | 材料没有的东西，有没有**编造**；该说"材料中未涉及"时有没有说 |
| **聚焦** | 有没有紧扣问题，不被无关楼层带跑 |

> 判为"差"的典型信号：关键词是一整句长句、命中数为 0、答案里出现材料中根本没提的数字/人名、答非所问。

## H. 专有名词 / 人名型（考锚点识别 + 空格组合查询 —— 重点）

> 这一组考察：能不能把**人名/机构名**当作锚点原样保留，并用「锚点 + 限定词」的空格组合去搜，
> 例如 `谭德志 实验室`、`谭德志 导师`，而不是拆成一堆互不相关的短词。

| # | 问题 | 考察点 | 期望表现 |
|---|---|---|---|
| H1 | 我的朋友想来浙大的谭德志老师实验室，请你帮他看看行不行 | 人名锚点 + 组合查询 | 关键词形如 `谭德志 实验室`、`谭德志 导师`、`谭德志 评价`、`谭德志`；"谭德志"三字必须完整保留 |
| H2 | 王小明老师的课给分高吗 | 人名 + 限定词 | `王小明 给分`、`王小明 课程`、`王小明` |
| H3 | 浙大 CAD&CG 实验室怎么样 | 机构名锚点 | 保留 `CAD&CG`，组合如 `CAD&CG 实验室`、`CAD&CG 科研` |
| H4 | 计算机学院李老师招研究生吗 | 姓氏+称谓 + 限定词 | `计算机学院 李老师`、`李老师 招生`、`李老师 研究生` |
| H5 | 想问问张伟师兄的导师是谁 | 人名 + 关系词 | `张伟 导师`、`张伟 师兄`、`张伟` |

**判差信号**：关键词里出现了`怎么样/行不行/帮我看看`等虚词；人名被拆开（如"谭德"、"德志"）；或只搜了"实验室"这种泛词而丢掉人名。

## 使用建议

1. 先跑 **C 组**（多概念长句）——最能暴露"关键词太长"的问题。
2. 再跑 **E 组**（材料外）——最能暴露"编造/硬答"的问题。
3. 最后跑 **A/B/D/F/G** 看常规表现。
4. 建议开启「调试日志」，这样能同时在 Service Worker 控制台看到拆出的关键词与每个词的命中数。
