CC98 AI 总结 — 选项

配置 AI 接口与抓取速度/防封参数

CC98 登录令牌

插件会自动捕获你在 cc98.org 页面浏览时使用的登录令牌（后台只读观察请求头， 不重新登录、不存账号密码，最不易触发风控）。正常浏览 cc98 任意页面即可自动获取。 仅当自动捕获失效时才需手动粘贴：cc98 页面 F12 → Network → 过滤 api.cc98.org → 点任意请求 → Request Headers 里的 authorization: Bearer … 后面整串。

DeepSeek API

防封号 / 速度限制

不同帖子可并发抓取（像多开标签页），每个帖子内部仍串行 + 随机间隔。 间隔越大越安全但越慢；触发限流（429/403/5xx）时自动指数退避重试。
