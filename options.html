配置 AI 接口与抓取速度/防封参数

CC98 登录令牌

插件会自动捕获你在 cc98.org 页面浏览时使用的登录令牌（后台只读观察请求头， 不重新登录、不存账号密码，最不易触发风控）。正常浏览 cc98 任意页面即可自动获取。 仅当自动捕获失效时才需手动粘贴：cc98 页面 F12 → Network → 过滤 api.cc98.org → 点任意请求 → Request Headers 里的 authorization: Bearer … 后面整串。

DeepSeek API

防封号 / 速度限制

速度参数已硬编码（如需调整请修改 background.js 里的 RATE 常量）：

并发抓帖 3 · 基础间隔 1500ms · 抖动 1500ms · 全局最小间隔 150ms · 搜索间隔 5000ms · 每页 20 层 · 每帖最多 5 页 · 字符上限 60000 · 限流重试 3 次

触发限流（429/403/5xx）时仍会自动指数退避重试，连续失败自动暂停保护账号。

智能搜索

问题式搜索：先拆多组关键词检索（弥补 cc98 无模糊搜索），再抓前若干篇内容交给 AI 合成答案。
